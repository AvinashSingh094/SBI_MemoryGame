# SBI_MemoryGame

A web-based 60-second Memory Card Match game built with React, Tailwind CSS, and Vite, featuring SBI financial plan themed cards.

## Features
- **Start Screen**: Clean interface with immediate Start Game CTA.
- **2-Second Card Preview**: Initial memorization preview before the round begins.
- **60-Second Countdown**: Real-time timer.
- **3D Card Flip Animations**: Interactive card flips and matching mechanics.
- **Built-in Sound Effects**: Procedural Web Audio API sound effects.
- **Result Screen**: Shows time taken with easy restart.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
